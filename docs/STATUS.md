# 참고 · 검증 범위 · 온라인 AI

2026-10-14 · v0.1.0 최초 배포판. 사용자 승인으로 내부 온라인 AI v0.1.6의 기능을 반영했습니다. 배포 릴리스 게시와 저장소 전체 공개는 별개이며 저장소 권한은 변경하지 않습니다.

기준 버전·커밋과 배포용 이름/문서 변환은 UPSTREAM.json에 기록합니다. 개인 서버 설정·운영 로그·실제 원음·인증정보는 배포 코드에 포함하지 않습니다. 문서에 등장하는 GitHub 소유자명은 공식 배포 저장소 주소입니다.

## 이번 배포판에서 확인한 범위

- TypeScript·빌드 통과. JavaScript 회귀 38/38, Python 전사 계약 3/3 통과.
- 실제 Chrome 모의 처리 5/5: 스피너 회전·단계 전환·완료·전사/정리/저장 실패·처리 중 닫기 및 재시도 상태 확인. OS 동작 줄이기 지원.
- 저장 폴더 검사 5/5: 새 설치·이전 기본값 두 종류·사용자 지정 경로·보관함 루트 설정. 이전 기본값은 회의록-온라인AI로 전환하고 기존 파일은 이동하지 않음. 서버 주소·토큰·처리 방식·자동 저장 설정 보존.
- 배포 소스 및 플러그인/서버 ZIP의 이름·개인정보·실제 비밀값 제외·현행 문서 링크 검사. 게시 전 별도 빈 경로에 서버 ZIP을 풀어 의존성 없는 Node 서버의 로딩·로컬 HTTP 계약을 확인.
- 게시 후 GitHub 설치 ZIP을 실제 재다운로드해 SHA256SUMS와 로컬 패키지의 SHA256·manifest를 대조.

검사 근거는 소스·패키지에 대한 검증이며 다른 사용자의 실제 계정이나 마이크 전체 흐름을 대신하지 않습니다. UI 시나리오의 서버 응답은 모의값이며 실제 AI·전사 호출은 실행하지 않았습니다.

## 기존 내부판 검증과 미검증 항목

기존 내부판의 LAN/HTTPS 경로에서 공개 한국어 음성 전사와 합성 Codex 정리가 성공한 기록이 있습니다. 다른 계정/서버·실제 사용자 마이크→보관함 저장·macOS 서버·모바일·긴 회의·재부팅 자동실행 검증으로 확대하지 않습니다.

음성은 본인이 운영하는 처리 서버의 Whisper가 맡고 전사 텍스트 정리는 선택한 온라인 AI로 전송합니다. 건강 상태 응답만으로 전사·정리가 성공했다고 판단하지 않습니다. 회의록은 원문과 대조하는 AI 초안입니다.
