# 검증 범위 · 온라인 AI v0.1.1

기준일:2026-10-15. 사용자 공개 릴리즈 요청에 따라 내부 온라인 AI v0.1.12의 기능을 선별 반영했습니다. 기준 커밋·일반화 변환은 UPSTREAM.json을 확인합니다. 내부 Git 이력·개인 서버 주소·실제 환경/인증/원음·운영 로그는 복사하지 않습니다.

## 내부판에서 이미 확인한 범위

- 실제 Linux CPU 서버와 macOS Obsidian에서 공개 한국어 음성을 사용한 녹음 중 터보 구간 전사·전체 원음 한 파일 보관·회의록 자동 저장을 확인했습니다. 사용자 실제 회의 음성을 공개하거나 사용한 시험이 아닙니다.
- 같은120초 공개 한국어 낭독 반복 표본의 순수 추론은30초 분할 약89초·40초 분할 약122초였습니다. 모델 로딩·통신은 별도이며 이 결과가 다른 서버/실제 회의의 속도 보장은 아닙니다.
- 약75초 내부 앱 시험도 녹음 종료 후 회의록 저장까지 약61초가 추가로 걸렸습니다. 구간 분할은 즉시 완료·실시간 추종을 보장하지 않습니다.
- 작업 ID 재사용·실제 취소·무음 완료·미완료 이어받기·기존 노트/원음/설정 보존을 검증한 변경을 반영했습니다.

## 공개판 검수

- TypeScript 타입 검사·프로덕션 빌드 통과.
- JavaScript 회귀86/86, Python 전사·취소·중복 방지·복구 계약16/16 통과. 테스트의 AI/전사 응답은 모의값입니다.
- 플러그인3파일·서버19파일의 ZIP 허용 목록·버전/ID·SHA256·현행 문서 링크32개·개인 설정 제외 검수 통과. 별도 압축 해제 환경의 로컬 HTTP6계약과 Python 모듈 로딩, 영구/임시 서비스 중복 실행 방지3경로를 확인했습니다. HTTP의 STT 응답은 모의값이며 실제 음성 추론이 아닙니다.
- GitHub 게시 후 설치 파일을 실제 재다운로드해 SHA256SUMS·로컬 파일 해시·manifest를 대조합니다.

내부판 실제 시험과 공개판 모의 회귀는 별도입니다. 이번 공개판 검수는 실제 AI/음성 API를 추가 호출하거나 다른 사용자 계정·마이크의 전체 흐름을 시험하지 않습니다.

## 미검증·한계

실제 Zoom 통화·마이크/이어폰/시스템 오디오의 OS·장치별 조합, 실제50분 이상 회의의 완료/인식 품질, 모바일 전체 흐름, Windows/macOS 처리 서버, 재부팅 후 자동실행은 별도 실기기 검증이 필요합니다. 화자 분리는 지원하지 않습니다. 강제 구간 경계의 문맥·숫자·고유명사는 원음과 대조합니다.

음성은 사용자가 지정한 처리 서버 Whisper로, 전사 텍스트는 선택한 온라인 AI로 전송합니다. 별도 음성 API를 선택하면 해당 제공자에도 음성이 전송됩니다. 회의록은 검토가 필요한 AI 초안이며 health 성공만으로 실제 전사·정리·저장 성공을 주장하지 않습니다.
