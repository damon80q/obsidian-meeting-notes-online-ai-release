# AI 회의록 · 온라인 AI

**옵시디언에서 회의를 녹음하면, 말한 내용을 글로 옮기고 요약·결정사항·할 일을 회의록으로 정리합니다.** 원본 녹음, 말한 내용을 옮긴 전사문, 정리된 회의록을 보관함에 저장합니다. 회의록은 검토·수정할 수 있는 마크다운 문서입니다.

**[설치·설정 시작하기](docs/SETUP.md)** · **[v0.1.1 다운로드](https://github.com/damon80q/obsidian-meeting-notes-online-ai-release/releases/tag/v0.1.1)** · **[전사 방식 고르기](docs/TRANSCRIPTION.md)**

## 처음 오셨다면 이것부터 확인하세요

- **옵시디언 플러그인 + 처리 서버가 함께 필요합니다.** 플러그인만 설치하면 AI 처리가 바로 되는 서비스는 아닙니다. 본인 컴퓨터에 서버를 준비하거나, 담당자가 제공한 서버 주소와 접속 토큰을 사용합니다.
- **‘전사’는 음성을 글로 바꾸는 일**, **‘정리’는 그 글로 회의록을 만드는 일**입니다. 두 단계는 서로 다른 AI가 맡습니다.
- ‘온라인 AI’는 **회의록 정리에 온라인 AI를 사용한다**는 뜻입니다. 기본 설정에서 음성은 지정한 서버의 Whisper가 처리하고, 전사된 글을 온라인 AI에 보냅니다. 음성을 OpenAI에 직접 보내는 방식은 별도 선택 설정입니다.
- OpenClaw 등 별도 에이전트 앱은 필요하지 않습니다. 옵시디언 커뮤니티 플러그인 목록에는 아직 등록되지 않아 아래 ZIP으로 직접 설치합니다.

```mermaid
flowchart LR
    A["회의 녹음"] --> B["음성 → 글<br/>처리 서버의 Whisper"]
    B --> C["글 → 회의록<br/>온라인 AI"]
    C --> D["옵시디언 보관함에 저장"]
```

온라인 AI의 로그인·이용 한도가 필요합니다. 기본 로그인 방식과 선택형 유료 API의 차이는 [설치 안내](docs/SETUP.md#3-텍스트-ai-준비)에 설명했습니다.

## 어떤 파일을 받고, 어디서 시작하나요?

| 내 상황 | 필요한 파일·안내 |
| --- | --- |
| 담당자에게 서버 주소와 접속 토큰을 받았습니다 | [플러그인 ZIP](https://github.com/damon80q/obsidian-meeting-notes-online-ai-release/releases/download/v0.1.1/ai-meeting-notes-online-0.1.1.zip)만 받고, [설치 안내 5번](docs/SETUP.md#5-플러그인-설치주소설정)부터 진행하세요. |
| 처리 서버도 직접 준비합니다 | [서버 ZIP](https://github.com/damon80q/obsidian-meeting-notes-online-ai-release/releases/download/v0.1.1/ai-meeting-notes-online-server-0.1.1.zip)과 플러그인 ZIP이 필요합니다. [설치 안내 1번](docs/SETUP.md#1-서버-컴퓨터와-설치-폴더)부터 진행하세요. |
| 공개판 v0.1.0을 이미 사용 중입니다 | [업데이트 순서](docs/SETUP.md#v010--v011-업데이트)를 확인하세요. 서버 담당자의 서버 업데이트도 필요합니다. |

다운로드 페이지의 **Assets(첨부 파일)**에서 위 ZIP을 찾을 수 있습니다. **Source code (zip/tar.gz)는 플러그인 설치 파일이 아닙니다.** `SHA256SUMS.txt`는 다운로드 파일이 손상되지 않았는지 확인하는 체크섬입니다.

기존 사용자는 같은 `ai-meeting-notes-online` 폴더의 `main.js`·`manifest.json`·`styles.css`만 교체하고 **설정 파일 `data.json`과 기존 녹음·노트는 보존**합니다. 서버를 제공받는 사용자가 서버를 직접 재설치할 필요는 없습니다.

## ‘터보’와 ‘스몰’은 무엇이고, 무엇을 고르면 되나요?

둘 다 **말소리를 글로 바꾸는 Whisper 음성인식 모델의 이름**입니다. 회의록을 요약하는 온라인 AI의 이름이나 요금제 이름이 아닙니다. 모델 이름을 외울 필요 없이 **언제 처리할지, 서버 부담을 줄일지**로 선택하세요.

| 쉽게 고르는 기준 | 현재 앱에 표시되는 선택명 | 실제 동작 |
| --- | --- | --- |
| **기본형 · 처음에는 이 방식으로 시작** | `터보 · 녹음 중 구간 전사 (약30초)` | 기본 음성인식 모델(`large-v3-turbo`)로 녹음 중 약 30초 분량씩 글로 바꿉니다. 지원 서버에서 기본 선택됩니다. |
| **경량형 · 서버 부담을 줄이고 싶을 때** | `빠르게 · 녹음 중 전사 / 파일 구간 전사` | 더 작은 모델(`small`, 스몰)을 사용하는 선택형입니다. 서버 담당자의 추가 준비가 필요하며, 인식 정확도가 낮아질 수 있습니다. |
| **종료 후 전체 처리 · 녹음이 끝난 뒤 시작하고 싶을 때** | `정밀하게 · 녹음 종료 후 전체 전사` | 전체 녹음을 종료 후 처리합니다. 기본형과 같은 모델을 쓰며, 더 큰 별도 모델로 바뀌는 것은 아닙니다. |

**‘약 30초’는 음성을 나누는 길이이지, 결과가 30초 안에 나온다는 뜻이 아닙니다.** 실제 대기는 서버 성능에 따라 달라집니다. ‘터보’가 모든 환경에서 가장 빠르거나, ‘정밀하게’가 언제나 더 정확하다는 보장도 아닙니다. 상세한 차이는 [전사 방식 안내](docs/TRANSCRIPTION.md)에 있습니다.

## 첫 회의는 이렇게 진행하세요

1. 명령 팔레트에서 **회의 정리 시작**을 엽니다.
2. 전송 대상을 확인하고 동의한 뒤, 대면회의라면 **마이크만**, 컴퓨터의 상대방 소리도 필요하면 **마이크+컴퓨터 소리**를 선택합니다. 컴퓨터 소리 녹음은 데스크톱의 OS 권한·환경 지원이 필요합니다.
3. 지원 서버에서는 **기본형(앱의 ‘터보’)**을 선택하고 녹음을 시작합니다. 처리된 글이 차례로 나타납니다. 즉시 자막처럼 한 글자씩 나오는 방식은 아닙니다.
4. **녹음 종료·정리**를 누릅니다. **이미 글로 바꾼 구간은 재사용**하고, 아직 처리하지 못한 구간과 마지막 남은 음성만 마저 처리합니다. 그다음 전체 글을 온라인 AI가 회의록으로 정리합니다.
5. 자동 저장을 켜 두었다면 회의록이 저장되고 열립니다. 숫자·이름·담당·일정을 원음과 대조해 검토하세요.

녹음 종료 후에도 미처리 구간과 회의록 정리를 기다릴 수 있습니다. **기본형에서 처음부터 전체를 다시 전사하는 것은 아닙니다.** 단, ‘종료 후 전체 처리’나 ‘보관 원음 전체 다시 처리’를 직접 선택하면 전체 음성을 처리합니다.

## 무엇이 남고, 실패하면 어떻게 하나요?

- **원본 녹음 한 파일**, 말한 내용을 옮긴 **전사문**, 정리된 **회의록**을 보관합니다. 새 기본 회의록 폴더는 `회의록-온라인AI`이며 직접 정한 폴더는 유지됩니다.
- 처리 중 전사문은 한 문서에 누적합니다. 실패하면 확보한 원음·전사문을 보존하고 음성을 자동 재전송하지 않습니다.
- 중단된 구간만 마무리하려면 **미완료 구간 전사 → 구간 전사 계속**을 사용합니다. 원음을 처음부터 다시 처리하는 기능과 다릅니다.
- 기존 노트를 덮어쓰지 않습니다. 취소·다시 정리·복구 방법은 [전사 방식과 복구](docs/TRANSCRIPTION.md)를 확인하세요.

현재 회의록은 **검토가 필요한 AI 초안**입니다. 화자 자동 분리는 지원하지 않습니다. 실제 Zoom·장치별 컴퓨터 소리 녹음·장시간 회의·모바일 전체 흐름은 별도 확인이 필요합니다. 먼저 짧은 녹음으로 시험하세요.
